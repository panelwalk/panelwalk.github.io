בקצרה

  • האתר לא שומר עוגיות (cookies) ולא שומר שום דבר במכשיר שלך.
  • אין בו כלי ניתוח, מעקב, פרסומות או טפסים.
  • הוא לא טוען שום דבר משרתים של חברות אחרות. גם הגופן מאוחסן כאן.
  • שירות האחסון שלנו, GitHub Pages, רושם את כתובות ה-IP של המבקרים לצורכי אבטחה. אנחנו לא רואים את הרישומים האלה.

מי מפעיל את האתר

Panelwalk (שם זמני) מפעיל את panelwalk.github.io ואחראי עליו. לשאלות בנושא פרטיות, שלחו הודעה פרטית ל-@panelwalkgames באינסטגרם או בבלוסקיי. בהמשך נוסיף לדף הזה כתובת דוא״ל ליצירת קשר. עד אז, אפשר לפנות אלינו בהודעה פרטית.

כשנכנסים לאתר

האתר מאוחסן ב-GitHub Pages, שירות של חברת GitHub. לפי GitHub, כשמישהו נכנס לאתר שמאוחסן אצלם, כתובת ה-IP שלו נרשמת ונשמרת לצורכי אבטחה (התיעוד של GitHub, באנגלית). GitHub נמצאת בארצות הברית ועשויה לעבד את המידע שם. אנחנו לא מקבלים את הרישומים האלה ולא יכולים לדעת מי נכנס לאתר.

מטרת העיבוד היא להציג את האתר בצורה מאובטחת, וזה אינטרס לגיטימי (Art. 6(1)(f) GDPR). לפרטים, כולל כמה זמן GitHub שומרת את הרישומים, ראו את הצהרת הפרטיות של GitHub (באנגלית).

עוגיות ואחסון

אין. האתר לא שומר עוגיות ולא משתמש באחסון המקומי של הדפדפן, ולכן אין למה לתת הסכמה. הדפדפן שלך עשוי לשמור עותק של קבצי הדף במטמון, כמו בכל אתר.

קישורים לאתרים אחרים

אנחנו מקשרים לאינסטגרם, לבלוסקיי ול-itch.io, שם נמצא המשחק שלנו. כשעוברים לאתר אחר, חלה עליו מדיניות הפרטיות שלו, למשל של אינסטגרם, של בלוסקיי ושל itch.io.

המשחק שלנו, The Ice Cream Palace, רץ ב-itch.io. הוא שומר את ההתקדמות וההגדרות שלך בדפדפן שלך ולא שולח לנו כלום.

כששולחים לנו הודעה

כששולחים לנו הודעה פרטית, אנחנו מקבלים את מה שהפלטפורמה מציגה לנו: שם המשתמש, הפרופיל וההודעה. אנחנו משתמשים בהם רק כדי לענות ולדבר על משחק אפשרי. אם שולחים לנו עמודי קומיקס לדוגמה חינמית, אנחנו משתמשים בהם רק כדי להכין את הדוגמה הפרטית שלך. אנחנו לא מוכרים מידע ולא משתמשים בו לפרסום.

מטרת העיבוד היא לענות לפנייה שלך, ואם תרצו, להכין איתך הסכם (Art. 6(1)(b) GDPR).

כמה זמן אנחנו שומרים את המידע

אנחנו מוחקים את ההודעות שלך ואת עמודי הקומיקס ששלחת לנו 3 חודשים אחרי שהשיחה מסתיימת, אלא אם סיכמנו על עסקה. אם סיכמנו, אנחנו שומרים אותם כל עוד ההסכם בינינו דורש זאת.

אם הכנו משחק לדוגמה מהעמודים שלך, אנחנו מוחקים אותו כשמבקשים מאיתנו, או תוך אותם 3 חודשים אם לא נסגרה עסקה.

הזכויות שלך

אפשר לבקש מאיתנו לדעת איזה מידע יש לנו עליך, ולבקש לתקן אותו, למחוק אותו, להגביל את השימוש בו או להתנגד לשימוש בו. כדי לעשות את זה, שלחו לנו הודעה פרטית.

אפשר גם להגיש תלונה לרשות להגנת מידע. בישראל זו הרשות להגנת הפרטיות. באיחוד האירופי זו בדרך כלל הרשות במדינה שבה גרים (רשימת הרשויות באיחוד, באנגלית).
